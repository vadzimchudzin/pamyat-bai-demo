# ПАМЯТЬ.БАЙ — сайт и админка

Статический сайт + серверные функции Vercel (`/api`) + база Postgres (Neon).

## Что настроить в Vercel (один раз)

**1. База данных.** Vercel → проект → Storage → Create → **Neon (Postgres)** → Connect.
Vercel сам добавит переменную `DATABASE_URL` (или `POSTGRES_URL` — тоже подходит).
Таблицы создаются автоматически при первом запросе.

**2. Переменные окружения** (Settings → Environment Variables):

| Переменная | Значение |
|---|---|
| `ADMIN_LOGIN` | логин для первого входа в админку |
| `ADMIN_PASSWORD` | пароль для первого входа (потом смените в админке → «Безопасность») |
| `SESSION_SECRET` | любая длинная случайная строка (40+ символов) |

После добавления — **Redeploy**.

**3. Вход:** `https://<сайт>/admin` (ссылка «вход» — еле заметная, в подвале сайта рядом с правовой информацией).

## Что есть в админке

- **Заявки** — канбан из восьми статусов, цвет каждой колонки, перелив/подсветка новых заявок, перенос карточек мышью или смена статуса в карточке. Статус отражается в Telegram.
- **Калькулятор сайта** — шаги и позиции можно редактировать вручную. Флаг «Использовать актуальный каталог цен» включает подстановку цен из финансового прайс-листа; для цены задаётся точное соответствие позиции сайта.
- **Примеры работ** — загрузка фото (сжимаются автоматически), подписи, порядок.
- **Тексты** — заголовки и тексты главной.
- **Контакты и номера** — телефон, Telegram, Viber, WhatsApp, Instagram, почта, ИП/УНП.
- **Telegram-бот** — таблица заявки, управление статусом, кнопка «Получить смету», кнопки перехода по этапам.
- **Финансовый отдел → Актуальный каталог цен** — импорт CSV/TSV (экспорт из Excel), правка наименований, единиц, цен и привязки к цене сайта.
- **Финансовый отдел → Сметы** — черновик по заявке, редактирование позиций/количества/цен/скидки, сохранение, ссылка и печать/экспорт в PDF со шапкой ПАМЯТЬ.БАЙ.
- **Журнал** — входы (в т.ч. неудачные), изменения, загрузки, действия в Telegram.
- **Безопасность** — смена логина и пароля. После 8 неудачных попыток вход блокируется на 15 минут.

## Файлы

- `index.html`, `css/dusk.css`, `js/site.js` — главная.
- `catalog.html` — каталог (собирается из исходного каталога партнёра, структура не менялась).
- `admin.html`, `css/admin.css`, `js/admin.js` — админка.
- `api/` — серверные функции: `auth`, `content`, `upload`, `img`, `lead`, `tg`, `finance`, `log`.
- `estimate.html`, `css/estimate.css`, `js/estimate.js` — печатная смета с уникальной ссылкой.
- `preview.html` — превью всего сайта одним файлом.
