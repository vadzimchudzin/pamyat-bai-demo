Каталог

Разделы каталога = первый шаг калькулятора (название для калькулятора — «Короткое»; цена — «от»). Пустая цена = «Индивидуальный расчёт». Обложка — один элемент крупным планом; «Масштаб» приближает его. Модели внутри раздела открываются по клику.

Калькулятор

Шаг 1 «Памятник» берётся из раздела «Каталог» автоматически. Ниже — остальные шаги. «Один вариант» — круглые переключатели, «несколько» — овальные тумблеры. Пустая цена = «индивидуальный расчёт». Подпись вместо цены — например «включено».

        Как подключить:

        1. В Telegram откройте @BotFather → /newbot → скопируйте токен сюда.

        2. Добавьте бота в закрытую группу менеджеров и сделайте его администратором.

        3. ID группы: перешлите любое сообщение из группы боту @getidsbot (ID начинается с -100…).

        4. Нажмите «Сохранить», затем «Отправить тестовое сообщение» и «Подключить кнопки».
